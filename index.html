01 /

Stock
Prediction

Reproducible stock research with immutable snapshots and purged walk-forward validation.

Technologies Python · DuckDB · Parquet · LightGBM

View source for Stock Prediction (opens a new tab)
Details

My work

I built the research pipeline around immutable Parquet snapshots, a DuckDB catalog, point-in-time features, and model evaluation with purged walk-forward folds.

Research boundaries

The public repository includes deterministic offline demos using synthetic data. These check reproducibility and leakage controls; they do not establish predictive lift or future returns. The platform does not place orders.

How it connects

This project focuses on stock-specific data and validation, alongside the broader multi-market workflow in Quant Model.

02 /

Quant
Model

A local-first research platform connecting multi-market data, backtesting, APIs, and dashboards.

Technologies Python · Fastify · React · PostgreSQL

View source for Quant Model (opens a new tab)
Details

My work

I developed data ingestion, baseline signals, model overlays, and backtesting workflows for crypto, US equities, China A-shares, and benchmark indices, with a Fastify API and React interface for published research artifacts.

Research boundaries

Results depend on the ingested universe, data coverage, and validation period. Sample artifacts and historical backtests are research outputs, not evidence of live trading performance.

How it connects

The platform provides a broader multi-market workflow; Stock Prediction concentrates on reproducible stock experiments, while Options Heatmap explores options exposure visually.

03 /

Options
Heatmap

Strike-by-expiration heatmaps for gamma and estimated vanna exposure.

Technologies TypeScript · React · GEX · VEX

View source for Options Heatmap (opens a new tab)
Details

My work

I built a React and TypeScript interface for options exposure by strike and expiration, with call/put breakdowns and inspectable inputs such as open interest, gamma, vanna, and implied volatility.

Research boundaries

The public default uses demo data. Live data requires an explicitly enabled local OpenD connection. When provider vanna is unavailable, VEX uses a Black-Scholes estimate; it is not a broker-certified measure.

How it connects

This is the options visualization component of my independent research toolkit. It does not execute trades or establish forecasting performance.
