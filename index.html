Three projects

01

Options Heatmap

Sole full-stack developer — Dec 2024 — present

Gamma and vanna exposure mapped across every strike and expiration for SPY, QQQ, IWM, and mega-cap tech, so the key gamma levels can be read at a glance.

  • React and TypeScript interface with a Node API that reads moomoo OpenD option chains and falls back to demo data automatically.
  • GEX per 1% move from gamma, open interest, and spot price, netting call and put exposure by strike.
  • Black-Scholes vanna estimate when providers omit it, covered by Vitest unit tests.

TypeScript — React — Node.js — Vitest

NoteDemo data by default; live data needs a local OpenD connection enabled explicitly. Estimated VEX is not broker-certified. It places no trades.

02

Stock Prediction Research

Sole backend & machine learning developer — Aug 2024 — present

A stock prediction platform built so every experiment can be replayed exactly and no feature ever sees the future.

465
pytest tests
72
preregistered trials
  • Market data stored as immutable Parquet snapshots in a DuckDB catalog, making every experiment reproducible.
  • LightGBM and baseline models run on purged walk-forward folds, with leakage audits keeping features point-in-time.
  • A read-only FastAPI service so every pipeline stage can be inspected and verified.

Python — DuckDB — Parquet — LightGBM — FastAPI

NotePublic demos use synthetic data. They test reproducibility and leakage controls, not predictive lift or returns. No orders are placed.
