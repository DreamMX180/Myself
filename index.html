01

Stock Prediction

Sole developer — Aug 2024 — present

Forecasts 5- and 20-day return intervals for individual stocks, then checks them on data the model never saw.

91%
coverage of 90% intervals
0 / 8
strategies met gates
  • Point-in-time data store built from moomoo OpenD, so each backtest only uses information available on that date.
  • Return intervals made by scaling HAR volatility forecasts with empirical quantiles of normalized returns.
  • On held-out 2025–26 data, nominal 90% intervals covered 91% of stock returns at both 5- and 20-day horizons.
  • 8 strategy configs tested against 4 baselines after costs and overfitting checks; none met the deployment gates set in advance.
  • Paper-trading order state machine that persists each order before sending and reconciles with the broker after a restart.

Python — Polars — DuckDB — LightGBM — FastAPI — React

NoteResearch and paper trading only; no real orders are placed and no strategy has passed its gates. The current repository is private; the link goes to the earlier public v1, which runs on synthetic data.

02

UninstallPro

Sole developer — Nov 2026 — present

A Windows uninstaller that finds what a program leaves behind and says how sure it is before removing anything.

  • Finds and removes leftover files, registry keys, services, and scheduled tasks after an uninstall.
  • Rates a leftover high confidence only if it was in the pre-uninstall snapshot and no other installed app was detected using it.
  • Backs up registry keys, services, and tasks before deletion; restores are verified in Windows Sandbox tests.

Rust — Tauri 2 — Svelte

NoteUnsigned build; source not yet public. Files are deleted permanently by default, with the Recycle Bin as an option. Only registry keys, services, and tasks can be restored.

03

OpenNote

Sole developer — Oct 2026 — present

A local-first note app that keeps notes as plain Markdown files on your own disk, with no telemetry. Version 0.1.0 is out on GitHub.

  • LaTeX builds run in a no-network AppContainer, inside a kill-on-close Job Object that cleans up child processes.
  • Saves go through an fsynced temp file, an atomic rename, and a resumable journal.
  • Edits made outside the app are flagged as conflicts instead of being overwritten.

Rust — Tauri 2 — React — TypeScript

NoteEarly release with an unsigned installer. Interface translations are machine-assisted.

04

Options Heatmap

Sole full-stack developer — Dec 2024 — present

Gamma and vanna exposure mapped across every strike and expiration for SPY, QQQ, IWM, and mega-cap tech, so the key gamma levels can be read at a glance.

  • React and TypeScript interface with a Node API that reads moomoo OpenD option chains and falls back to demo data automatically.
  • GEX per 1% move from gamma, open interest, and spot price, netting call and put exposure by strike.
  • Black-Scholes vanna estimate when providers omit it, covered by Vitest unit tests.

TypeScript — React — Node.js — Vitest

NoteDemo data by default; live data needs a local OpenD connection enabled explicitly. Estimated VEX is not broker-certified. It places no trades.
