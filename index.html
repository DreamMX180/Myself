01

Stock Prediction

Sole developer — Aug 2024 — present

An end-to-end forecasting engine that predicts where each stock’s 5- and 20-day returns will land, and proves it on two years of data it never saw.

91%
out-of-sample coverage
513
automated tests
2 yrs
sealed holdout
  • Point-in-time market data engine on moomoo OpenD, with corporate actions and delisted names handled, so no backtest ever sees the future.
  • HAR volatility models and LightGBM LambdaRank ranking, combined into a calibrated return distribution for every stock.
  • Nailed calibration on a sealed 2025–26 lockbox: 90% intervals hit 90.9% and 91.3% coverage, beating the baseline on pinball loss in every test.
  • Institutional-grade validation: deflated Sharpe, overfitting probability, trading costs, and four baselines must all clear before a strategy ships.
  • Crash-safe order engine that persists every order before it is sent and reconciles with the broker after a restart.

Python — Polars — DuckDB — LightGBM — FastAPI — React

02

UninstallPro

Sole developer — Nov 2026 — present

A native Windows uninstaller that hunts down everything a program leaves behind and wipes it out, with a confidence score on every item.

10.7k
lines of Rust
90
unit tests
  • Snapshot-based detection that tracks down leftover files, registry keys, services, and scheduled tasks after every uninstall.
  • Every leftover is cross-checked against all other installed apps, so shared components are flagged instead of deleted.
  • Built-in restore for registry keys, services, and tasks, verified end to end in Windows Sandbox.
  • Hard-coded guardrails make system folders and critical registry keys impossible to delete.

Rust — Tauri 2 — Svelte — Win32

OpenNote

Sole developer — Oct 2026 — present

A privacy-first note app with built-in LaTeX: plain Markdown on your own disk, zero telemetry, shipped as an open-source release on GitHub.

78k
lines of Rust
1,064

  • Sandboxed LaTeX: every build runs in a no-network AppContainer under a kill-on-close Job Object, so nothing escapes and nothing lingers.
  • Crash-proof saves: fsynced temp files, atomic renames, and a resumable journal keep notes intact through crashes and power loss.
  • Conflict detection catches edits made outside the app instead of silently overwriting them.

Options Heatmap

Sole full-stack developer — Dec 2024 — present

Real-time gamma and vanna exposure across every strike and expiration for SPY, QQQ, IWM, and mega-cap tech: the levels dealers hedge around, readable at a glance.

  • React and TypeScript interface with a Node API that reads moomoo OpenD option chains and falls back to demo data automatically.
  • GEX per 1% move from gamma, open interest, and spot price, netting call and put exposure by strike.
  • Black-Scholes vanna estimate when providers omit it, covered by Vitest unit tests.
